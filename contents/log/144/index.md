# 生成AIがなかった時代への懐古

こんなにも生成AIが、人間に追いつき、そして追い抜き始めるとは、3年前の私はこれっぽっちも思っていませんでした。最初期のChatGPTはハルシネーションばかりで、人間が書いたコードの代わりに使えるようなものでは到底ありませんでした。誰も、生成AIで使える文章を書くなどということはしていなかったはずです。あくまで、技術的なおもちゃの範疇でしかありませんでした。GPT-3.5の時代の話です。

それから約4年。世界は不可逆的に変化しました。Claudeが生まれ、Geminiが生まれ、そしてClaude Codeが生まれ。インターネット上の景色は完全に変わりました。AI生成の記事、画像、動画、音楽が、あらゆるところで見られるようになりました。また、プログラミングの領域においては、生成AIを使わずに作ることのほうが珍しく感じられるほどになりました。

それぞれのコンテンツがどのように作られたのか。我々が知るすべは限られています。生成AIで作られたのか、人間の手で作られたのか。しかしこの時代において、その問いを持つこと自体にどれほどの意味があるのか。

私たちはもうあの、生成AIが世界を席巻する前の時代に戻ることはできないのでしょう。サイバー兵器としても機能しうる生成AIの進化を止めることは、自国の安全保障を諦めることにすなわち等しいからです。

あからさまなAI生成コンテンツへの拒否感が、私の中にないわけではありません——しかし、そんな思いはもはや、私の単なる懐古にすぎないのかもしれません。人間が、自分たちの手と頭で何かを作り上げる必要があった時代への懐古です。
