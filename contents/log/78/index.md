# 再びサイトデザインを改修。そして毎日更新がしたい

またサイトのデザインを回収しました。以前のデザインでは、サイドメニューが常に画面左に表示されていたのですが、それを廃して単にページトップに表示されるだけにしてみました。サイトロゴとfaviconに関しても、新しいものにしました。新年ということで、ちょうど良いタイミングではないでしょうか。

個人的にはこのデザインがかなり気に入っておりまして、これ以上大きな変更をするつもりがありません。確かにサイトに不足している機能を追加する予定はありますが、あまりこれ以上デザインを変えても、必ずしも良くなるわけではないと感じているからです。デザインには終わりがないのです。

むしろ私は、サイト上のコンテンツを増やすべきだと思うのです。もっと積極的にアウトプットをしていった方が、自分の為になりますし、世界の誰かの為にもなり得ます。ということで、今年は可能な限り毎日このサイトを更新したいと思います。

毎日更新は、必ずしも中身があるものになるかはわかりませんが、技術系のネタであれば豊富にあるので、できる気がします。まあ技術系だけでなくても良いですが。とにかく、自分用のメモに書き込むのではなくて、公開されているサイトに書いておくことに意味があるのです。
