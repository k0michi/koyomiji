# クリスマスの横須賀を巡り歩いた【艦これ横須賀遠征2025】

12月25日、12月26日にかけて、横須賀で開催されていた艦これのイベントに参加してきましたので、その時の記録です。今回の遠征のお目当ては、「横須賀鎮守府【重】スタンプラリー」でした。

夏の呉遠征で初めて艦これのリアルイベントに参加したわけですが、その時はスタンプをコンプリートできなかったので、今回のスタンプラリーではその雪辱を晴らしたいと思っていたのです。

## 12月25日

25日は朝9時半ごろに横須賀駅に到着。

![](./DSC05793.JPG)

この日の最初のミッションは、11時から発売のエントリーシートを入手することでした。というのも、22日の時点で公式Xにてエントリーシートが枯渇したという話が出ておりまして、販売再開は24日以降というアナウンスがあったのです。呉のときは難なくエントリーシートを入手することができましたが、今回はまた違う状況かもしれないと思い、余裕を持って現地に向かいました。

販売場所のヴェルニー公園に向かいますと、そこにはすでに長蛇の列が。しかし、何の列であるかはよく分からず。並んでいる方にお話を伺いますと、これは物販の列だろうとのことでした。ただ、これ以外の列が形成されているということもなく、11時まではまだ時間があったので、とりあえず並んで物販の様子を伺ってみることにしました。

![](./DSC05589.JPG)

10時になり、物販の販売が始まります。グッズの名前と値段の一覧が書かれた紙が配られるわけですが、完売のコールは鳴り止まず。電と雷のアクリルスタンドが一覧あったので、欲しいなと思っていたのですが、購入することは叶いませんでした。他には飛龍のアクスタもあり欲しいと思ったのですが、こちらも完売。

![](./IMG_7723.jpeg)

グッズの実物が飾られていたのでそれを眺めておりますと、それまで気に留めていなかった高波のマグカップの絵柄が気に入ったので思わず購入。

![](./IMG_7725.jpeg)

その後、エントリーシートの購入列ができていたので、並んで無事にエントリーシートを購入。一つ目はスタート地点のヴェルニー公園なので、購入後にその場で押してもらえます。

![](./DSC05604.JPG)

さて、今回のスタンプ地点ですが……なんと10地点。

![](./DSC05607.JPG)

とはいえ、基本的には駅の周辺に設置されているため、今回の持ち時間である2日間で十分回りきれるだろう、と高を括ります。ただし、猿島を除いては。

![](./DSC05606.JPG)

そうです、今回の一番の懸念は、猿島にありました。何故かといえば、この前日の24日ごろから雨が降ったりと天気があまり良くなかったからです。天気次第で、猿島への交通手段が絶たれるという可能性が考えられました。

さて、この日の行動計画ですが、まずは横須賀駅周辺のスタンプを入手し、その後時間があれば浦賀の3つを回収することにしました。猿島を最初に攻めるという考えもあるにはあったのですが、画像にもあるように今回のルールでは猿島は行かずとも景品が貰えるということなので、他の地点を優先することとしました。

### 平和中央公園

さて、次は平和中央公園ですが、この公園、地図上で見ると結構広く、公園のどこにスタンプがあるのかがいまいちわかりませんでした。西と南から道が繋がっているようだったので、とりあえずその辺りを目指すことに。

## 12月26日

次の日。この日も朝9時半ごろに横須賀駅に到着。この日は10:50からリモート授業があったため、計画としては、まず猿島航路のチケットだけ念の為先に入手、12:30に授業が終わってから三笠公園、13:30の航路で猿島、衣笠商店街の順で訪問、ということを考えていました。

ということで、まずはバスで三笠公園へ。

![](./DSC05875.JPG)

ターミナルにて、チケットを購入。

![](./IMG_7746.jpeg)

コラボチケットは缶バッジ付きです。絵柄は阿武隈を選択。

![](./IMG_7750.jpeg)

ネット環境のあるカフェを求めて、コースカベイサイドストーアズの方に戻ってきました。

![](./DSC05896.JPG)

4階の映画館にて、劇場版艦これのパネルを発見。リバイバル上映をやっていたみたいですね。正月modeの睦月ちゃん良き！

![](./IMG_7752.jpeg)

タリーズにて授業を受けていたのですが、ありがたいことに15分ほど早く授業が終わりました。

![](./IMG_7760.jpeg)

なぜありがたいかと言いますと、12:25の久里浜行きで衣笠を先に回れるからです。衣笠から行って戻って来て、13:30の猿島航路に間に合わせようという作戦です。急いで横須賀駅へ。

![](./IMG_7762.jpeg)

衣笠に到着。時刻は12:32。12:49発の電車で横須賀に戻らねばならないので、時間的にはかなりタイトです。

![](./DSC05902.JPG)

さて、この衣笠商店街なのですが、あらゆるところに衣笠さんの張り紙がされています。すごい。

![](./IMG_7765.jpeg)

ただ、あまりゆっくり見る時間はありません。8つ目のスタンプを入手。

![](./DSC05907.JPG)

衣笠駅に戻ってきました。時刻は12:45。12:49の成田空港行きで、横須賀へ戻ります。

### 猿島

出航の時間が近いので、猿島航路に乗船。この日は晴れていたのですが、風がとにかく強かったです。

![](./DSC05978.JPG)

![](./DSC06059.JPG)

猿島に上陸。お腹が空いていたので、オーシャンズキッチンの串カツと、コラボのレモネードをいただきました。この日は風が強かったので、暖かいレモネードはありがたい。

![](./IMG_7777.jpeg)

そしてついに、最後となる阿武隈のスタンプを入手。順番的に、猿島を最後に取っておいて正解だった気がします。

![](./IMG_7785.jpeg)

帰りの船が来るまで、猿島を少しだけ見ていました。奥の方に行く元気はありませんでしたが。

![](./DSC06115.JPG)

![](./DSC06152.JPG)

![](./DSC06161.JPG)

この日は本当に風が強く、悪天候のため帰りの便は14:45で最終になるという旨のアナウンスがなされていました。普段であれば16:00が最終です。このためもちろん、やってくる船には乗客が乗っておりません。もし13:30の便に乗れていなかったら、この日のコンプリートは不可能になるところでした。

![](./DSC06213.JPG)

帰りの便はこれでもかというほど揺れましたが、無事に三笠公園に帰還。

![](./DSC06225.JPG)
