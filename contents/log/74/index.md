# 最近全然ブログを書けていない話

このところ、このブログの更新が滞りつつあります。実はそれでも、書きたいことはかなり山積みになっておりまして。なのにも関わらず、ブログを書こうとすると書けない、という謎の現象に陥っているのです。

記事のアイデア自体はあるのです。そして、それをメモ帳の上で言語化するところまでは容易いのです。しかし、それを記事という形で書き上げるのが何故か上手くいかないのです。

ということで、私が今妄想している私なりの記事の書き方というのがあります。それは、メモ帳の上でドラフトを作り上げてしまう、というものです。もっと言えば、メモ帳の上で直接記事を書けてしまえば良いのでは？とも思っています。

あるいは、文章の書き方を勉強する、というのも選択肢の一つでしょう。今のところは完全に気分で書いてしまっているので。まあ、メモ帳はもっと気分で書いているのですが。

あとは単純に時間がかかるということでしょうか？メモ帳ならば、自分が分かればいいので脈絡などありませんが、ブログ記事ならばある程度道筋を順番に辿る必要があるのです。それは、必要な情報を限りなく少ない文字数で表現する私のメモ帳と全く正反対の代物です。

どうにかして、メモ帳とブログの壁を取っ払いたいところです。Markdownが肌に合わない、というところが大きいのかもしれません。
