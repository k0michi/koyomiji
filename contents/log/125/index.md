# GitHub Copilot Chatの言語を日本語にする【VSCode】

GitHub Copilot Chatは便利なのですが、VSCodeの言語設定が英語の場合、Copilotも英語で回答します。VSCode側の言語を変更せず、Copilotの言語だけを日本語にする方法があったので共有します。

1. 設定を開き"locale override"で検索します。

![](./Screenshot%202025-06-24%20at%2020.01.11.png)

2. "Locale Override"を"ja"にします。

これで、わざわざ日本語で聞かなくても勝手に日本語で回答してくれるようになります。
